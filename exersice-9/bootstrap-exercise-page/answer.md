# Bootstrap foundations: my answers

## 1. What does Bootstrap do when your HTML uses `class="btn btn-primary"`?
In Bootstrap, .btn styles the element as a button, and .btn-primary applies the primary theme color.

## 2. Why does this lesson load Bootstrap before `custom.css`?
This is because if run before bootstrap it will affect the colour,size that you may not able to change it or change it without effect.

## 3. What are the three main layers in the nesting pattern of the Bootstrap grid?
Container,row,columns

## 4. Which two navbar values must be the same, so that the collapsing menu works?
This is because it must have the same attribute

## 5. Which parts of the pattern lab come from Bootstrap, and which parts come from `custom.css`?
The layout containers, grid rows or columns are from Bootstrap and the part from css is the colour form size and also the hover.
